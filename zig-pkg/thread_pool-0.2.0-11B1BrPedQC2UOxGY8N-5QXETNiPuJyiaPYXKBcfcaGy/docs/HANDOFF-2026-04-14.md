## Measurement Rules (enforced by project policy)

These rules come from prior-session lessons (feedback_perf_profiling.md in memory). Break them at your peril.

1. **Paired same-session A/B is the ONLY valid comparison methodology.** Absolute numbers across sessions are uncomparable due to host drift. Always measure main and candidate within the same hour, same host conditions, direct binary invocation.
2. **n=10 minimum for flood_1m.** Fewer runs won't distinguish real deltas from the 15-20% inherent noise floor.
3. **Wall-clock per-thread + A/B-disable before planning any hot-path change.** Two prior attempts (G3, wake-gate) landed ~0% net because their ceilings were misattributed.
4. **20× ReleaseFast stress-test gate** for any submit-path change. 100× for pre-merge. Stress binary: `zig build test-stress -Doptimize=ReleaseFast`. Sentinel at `src/pool.zig:167` (`claim_sentinel_enabled = true`) catches double-dequeue races — keep active through any submit-path work.
5. **Host state check before accepting numbers:** uptime < 2 days (preferably fresh reboot), no co-tenant CPU-heavy processes, load avg 1m < 2.0, `schedutil` governor (verify live frequency sampling during bench, not just `cpufreq` reads).
6. **Host drift invalidates absolute claims.** 2026-04-14 audit found the "566K morning baseline" was actually 14:36 mid-afternoon with 2/10 outliers. Use medians not means. Treat distribution overlap as the correctness bar (if candidate's max doesn't exceed main's min, that's noise; if candidate's min exceeds main's max, that's decisive).

## Detailed Review — 2026-04-14 Option 3 Attempt (ABANDONED)

### What was built

Added per-worker `incoming: BoundedRing(u32)` queues. Non-worker-thread submitters rotate across them via `Core.incoming_cursor` atomic fetchAdd, up to `max_threads` probes, with fallback to the existing global `inject_queue`. ### Why flood_1m regressed

Single-submitter flood_1m:

- **OLD:** submitter pushes every task to one `inject_queue.tail` cacheline — hot in submitter's L1. Coherence storm as 56 workers read `head`.
- **NEW:** rotates across 56 worker `incoming.tail` cachelines — cold in submitter's L1 on every rotation. 56 forced cacheline misses per submit.

Cold-line traversal cost dominated the saved coherence storm. Mechanism predicted in the brainstorm.
