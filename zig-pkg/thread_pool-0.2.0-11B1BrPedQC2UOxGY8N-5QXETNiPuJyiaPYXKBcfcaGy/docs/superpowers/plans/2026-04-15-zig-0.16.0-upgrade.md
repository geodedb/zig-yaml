# Zig 0.16.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the `thread-pool` library from Zig 0.15.2 to Zig 0.16.0 so every suite (`test`, `test-integration`, `test-stress`, `bench`, `bench-tokio-parity`, `bench-realistic`, `bench-runtime-compare`, `scale-bench`, `compare-bench`, `bench-micro-*`) builds and passes on the new toolchain.

**Architecture:** 0.16.0 removed `std.Thread.Mutex/Condition/Semaphore`, `std.Thread.sleep`, `std.time.nanoTimestamp/timestamp/Timer`, `std.process.argsAlloc/Free`, and `std.fs.File.stdout()`, and replaced them with `std.Io`-based primitives that require an `Io` instance. We keep the library zero-setup by introducing two thin internal wrappers:
1. `src/sync.zig` — `Mutex`/`Condition`/`Semaphore` that reuse `std.Io.Mutex/Condition/Semaphore` internally but pass `std.Io.Threaded.global_single_threaded.io()` so callers still write `m.lock()/m.unlock()/c.wait(&m)` exactly as before. `futexWaitUncancelable`/`futexWake` in `Threaded.zig` ignore `userdata`, so the static global is safe on any thread.
2. `src/clock.zig` — `nanoTimestamp() i96` (via `Io.Clock.Timestamp.now(io, .awake)`, `userdata` ignored by `now`) and `sleep(ns: u64) void` (via `std.posix.nanosleep` / Windows `kernel32.Sleep`) — uncancelable, no allocator, callable from watchdog/tests/benches.

The `src/` library layer never takes an `Io` argument. Benchmark binaries switch `pub fn main() !void` to `pub fn main(init: std.process.Init) !void` to pick up `init.args`, `init.gpa`, and `init.io` for arg parsing, JSON, and `writeStreamingAll` calls. Fuzz tests migrate from the old `fn(ctx, []const u8)` signature to the new Smith-based `fn(ctx, *Smith)` signature using `smith.sliceWithHash(&buf, hash)` / `smith.valueWithHash(T, hash)`. `src/stats/process_memory.zig`'s Linux path switches to `std.posix.open` + `std.posix.read` since `std.fs.openFileAbsolute` no longer exists without an `Io`.

**Tech Stack:** Zig 0.16.0, `std.Io` (`Mutex`, `Condition`, `Semaphore`, `Clock.Timestamp`, `File`, `Dir`), `std.Io.Threaded.global_single_threaded`, `std.posix` (`nanosleep`, `open`, `read`, `close`), `std.testing.Smith`, `std.process.Init` / `std.process.Args.Iterator`, `std.ArrayList` (unchanged), `std.json.Stringify.valueAlloc` (unchanged).

```zig
//! Internal sync primitives that preserve the zero-arg API of 0.15.2
//! (`Mutex.lock/unlock`, `Condition.wait/signal/broadcast`, `Semaphore.wait/post`)
//! on top of 0.16.0's `std.Io`-based primitives.
//!
//! Implementation: call the `*Uncancelable` variants on a static
//! `std.Io.Threaded.global_single_threaded` instance. The futex vtable
//! functions in `std.Io.Threaded` ignore their `userdata` parameter for the
//! uncancelable path, so this is safe to call from any thread regardless of
//! whether it is registered with a `Threaded` runtime.

const std = @import("std");

inline fn io() std.Io {
    return std.Io.Threaded.global_single_threaded.io();
}

pub const Mutex = struct {
    inner: std.Io.Mutex = .init,

    pub fn lock(self: *Mutex) void {
        self.inner.lockUncancelable(io());
    }

    pub fn unlock(self: *Mutex) void {
        self.inner.unlock(io());
    }

    pub fn tryLock(self: *Mutex) bool {
        return self.inner.tryLock();
    }
};

pub const Condition = struct {
    inner: std.Io.Condition = .init,

    pub fn wait(self: *Condition, m: *Mutex) void {
        self.inner.waitUncancelable(io(), &m.inner);
    }

    pub fn signal(self: *Condition) void {
        self.inner.signal(io());
    }

    pub fn broadcast(self: *Condition) void {
        self.inner.broadcast(io());
    }
};

pub const Semaphore = struct {
    inner: std.Io.Semaphore = .{},

    pub fn wait(self: *Semaphore) void {
        self.inner.waitUncancelable(io());
    }

    pub fn post(self: *Semaphore) void {
        self.inner.post(io());
    }
};
```

```zig
//! Clock wrappers that preserve the zero-arg API of 0.15.2
//! (`std.time.nanoTimestamp`, `std.Thread.sleep`) on top of 0.16.0 primitives.
//!
//! `nanoTimestamp` uses `std.Io.Clock.Timestamp.now` on the static
//! `global_single_threaded` Io (the `now` vtable fn ignores `userdata`).
//!
//! `sleep` uses `std.posix.nanosleep` on POSIX and `kernel32.Sleep` on
//! Windows. Both are uncancelable and do not require any async state.

const std = @import("std");
const builtin = @import("builtin");

pub fn nanoTimestamp() i96 {
    const io = std.Io.Threaded.global_single_threaded.io();
    return std.Io.Clock.Timestamp.now(io, .real).raw.nanoseconds;
}

pub fn sleep(nanoseconds: u64) void {
    if (builtin.os.tag == .windows) {
        const ms: u32 = @intCast(@min(nanoseconds / std.time.ns_per_ms, @as(u64, std.math.maxInt(u32))));
        std.os.windows.kernel32.Sleep(ms);
        return;
    }

    const ns_per_s = std.time.ns_per_s;
    const sec: u64 = nanoseconds / ns_per_s;
    const nsec: u64 = nanoseconds % ns_per_s;
    var req: std.posix.timespec = .{
        .sec = @intCast(sec),
        .nsec = @intCast(nsec),
    };
    var rem: std.posix.timespec = undefined;
    while (true) {
        const rc = std.posix.system.nanosleep(&req, &rem);
        const err = std.posix.errno(rc);
        switch (err) {
            .SUCCESS => return,
            .INTR => {
                req = rem;
                continue;
            },
            else => return,
        }
    }
}
```

```zig
pub const WaitGroup = struct {
    pending: std.atomic.Value(u32) = std.atomic.Value(u32).init(0),
    mutex: sync.Mutex = .{},
    cond: sync.Condition = .{},

    pub fn add(self: *WaitGroup, delta: u32) void {
        _ = self.pending.fetchAdd(delta, .monotonic);
    }

    pub fn done(self: *WaitGroup) void {
        const previous = self.pending.fetchSub(1, .acq_rel);
        if (previous == 0) {
            @panic("WaitGroup: done() called more times than add()");
        }
        if (previous == 1) {
            self.mutex.lock();
            defer self.mutex.unlock();
            self.cond.broadcast();
        }
    }

    pub fn wait(self: *WaitGroup) void {
        self.mutex.lock();
        defer self.mutex.unlock();
        while (self.pending.load(.acquire) != 0) {
            self.cond.wait(&self.mutex);
        }
    }

    pub fn pendingCount(self: *const WaitGroup) u32 {
        return self.pending.load(.acquire);
    }
};
```
